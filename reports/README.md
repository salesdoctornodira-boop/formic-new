# CCS — Инфографик ҳисобот (опросник аналитикаси)

Асосий иловага (index.html / api / DB) **ҳеч қандай ўзгартириш киритилмаган** — булар мустақил артефактлар.

## ⚠️ Махфийлик
`CCS_Analytics_REAL_*` файллари **реал ходимлар исми, изоҳлари ва деанонимизация қилинган раҳбар баҳоларини**
сақлайди. Улар `reports/.gitignore` орқали git'дан **чиқариб ташланган** — GitHub'га юкланмайди. Пуш қилманг.

## Иккита пайплайн
### 1) Реал ҳисобот (асосий) — иловадан юклаб олинган .xlsx (deanon) асосида
```bash
bash reports/make_real_report.sh "~/Downloads/CCS_Evaluations_YYYY-MM-DD.xlsx"
```
Босқичлар: `xlsx_to_json.py` (deanon .xlsx → JSON) → `analyze_real.py` (аналитика) →
`generate_real.py` (инфографик HTML) → Chrome headless → PDF (`CCS_Analytics_REAL_<период>.pdf`).

### 2) Тест ҳисобот — репозиторийдаги тест `data/ccs.db` асосида
```bash
bash reports/make_report.sh
```
(`analyze.py` + `generate_report.py`; DB нусхасидан ўқийди, checksum текшируви билан — live DB ўзгармайди.)

## Ҳисоблаш усули (реал)
- **Общий балл** — Final (раҳбарлар) ва Peer (ҳамкасблар) 50% / 50% (сбалансированный балл).
  **Средний балл** — 4 қадрият бўйича оддий ўртача. **Всего** — олинган ҳамма балл. **Оценок** — неча киши баҳолаган.
  Пропущенные («билмайман») ва отклонённые баҳолар балл ичига кирмайди.
- **ТОП-15 — рейтинг доверия (Байес):** `(V/(V+M))·Балл + (M/(V+M))·C`, C — компания ўртачаси, M=10.
  Кўп одам тасдиқлаган яхши балл кўтарилади; 2–3 кишидан олинган юқори балл тасодифан юқорига чиқмайди
  (тўлиқ жадвал — **Приложение Б**).
- **Комментарии — фақат реал кейслар.** Ташланади: бўш/кўринмас, <10 белги, бир сўзли («хорошо»/«yaxshi»),
  «не знаю / не работал», ва **шаблонлар** (бир хил узун матн ≥5 марта = копипаст). Баллар ўзгармайди —
  фильтр фақат матнга тегади. Тўлиқ аудит (нима қолди/қолмади + шаблонлар рўйхати) — **Приложение А**.
- **Раҳбарлар изоҳлари исм-фамилия+лавозим билан** (deanon); оддий ходимлар аноним.

## Файллар
